⚙️ Dual-Engine Python Architecture & Deployment Specification

⚡ Mode 1: Local / Cloud Server (FastAPI + Python 3.14)

Designed for local development, clinical intranets, and containerized cloud deployments (Docker/Kubernetes).

  • High-throughput asynchronous REST API backed by Uvicorn and Starlette.
  • Pydantic v2 data validation with full JSON Schema compliance.
  • Interactive Swagger UI documentation accessible at /docs.
  • Direct integration with hospital EMR pipelines and external LLM/RAG sidecars.

🟢 Mode 2: Client-Side WebAssembly (Pyodide Wasm - GitHub Pages)

Enables 100% serverless, zero-cost deployment on GitHub Pages while executing the identical genuine Python modules.

  • Python 3 compiled to WebAssembly via Pyodide.
  • Runs the identical med_assistant Python package directly in the client browser's memory.
  • Zero backend infrastructure required: works completely offline once cached.
  • Absolute privacy: patient vignettes and research abstracts never leave the local browser session.
🛠️ Verification & Quickstart Commands
# 1. Clone repository

# 2. Install dependencies

# 3. Launch local FastAPI server
